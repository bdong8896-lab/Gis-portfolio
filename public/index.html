웹 GIS

토지정보 조회 시스템

위성영상 분할 화면, 지적·용도지역·건물·도로 레이어를 한 화면에 구성. 사업 구역에 걸린 필지의 편입 면적과 편입률을 자동 계산해 담당자의 수작업 계산을 없앴습니다.

OpenLayers · VWorld WFS/WMS · Turf.js · Kakao Maps
데스크톱 GIS

규제구역 GIS 뷰어

구역 데이터를 오프라인으로 띄우고 클릭 한 번으로 로드뷰를 확인하는 설치형 프로그램. 좌표계 불일치(EPSG:5181 ↔ 3857)와 SDK 인증 문제를 해결했습니다.

Electron · OpenLayers · VWorld WMTS · Kakao Roadview
데이터 처리

주소 4천여 건 일괄 정비 · 변환 도구

형식이 제각각인 도로명 주소 약 4,160건을 정규화하고, 지번 주소로 일괄 변환하는 브라우저 도구를 만들어 담당자가 직접 재사용할 수 있게 했습니다.

Python · openpyxl · Kakao Geocoder
인프라

04 / KNOWLEDGE

기술 지식 공유

현장에서 부딪히고 해결한 내용을 정리해 둡니다. 글은 계속 추가됩니다.

NOTE 01

좌표계가 어긋날 때: EPSG:5181 ↔ 3857

국내 지도 SDK와 웹 메르카토르 레이어를 함께 쓰면 위치가 수십~수백 미터씩 밀립니다. 어디서 좌표계가 섞이는지 찾고 변환 지점을 한 곳으로 모으는 방법.

OpenLayers · proj4 · 좌표 변환
NOTE 02

내부망에서 외부 지도 API 쓰기

IIS ARR 리버스 프록시로 외부 지도·주소 API를 내부망에서 안정적으로 호출하는 구성과, 막히기 쉬운 지점(SSL, 헤더, URL Rewrite) 점검 순서.

IIS ARR · URL Rewrite · SSL
NOTE 03

큰 GeoJSON을 가볍게: PMTiles

수십 MB짜리 경계 데이터를 tippecanoe로 타일화해 서버 없이 정적 파일로 서비스하는 흐름과, 줌 레벨별 단순화 설정.

tippecanoe · PMTiles · GeoJSON
NOTE 04

제각각인 주소 정리하기

엑셀에 섞여 있는 도로명·지번·약식 주소를 정규화하고 지오코딩해 좌표로 바꿀 때 자주 생기는 오류 유형과 대처법.

Python · openpyxl · Geocoder
