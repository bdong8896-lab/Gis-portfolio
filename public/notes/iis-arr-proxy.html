내부망에서 외부 지도 API 쓰기: IIS ARR 리버스 프록시

브라우저가 외부 지도·주소 API에 직접 닿지 못하는 환경에서, IIS의 ARR과 URL Rewrite로 프록시를 구성하는 순서와 막히기 쉬운 지점을 정리했습니다.

2026.10.13 작성

왜 프록시가 필요한가

업무망이나 내부망에서는 PC나 서버가 외부 인터넷에 직접 나가지 못하거나, 외부 API의 CORS·도메인 등록 정책 때문에 브라우저에서 곧바로 호출할 수 없는 경우가 있습니다. 이때 내부 웹서버가 대신 외부 API를 호출하도록 중계하면 사용자는 내부 주소만 알면 됩니다.

브라우저 ──▶ 내부 IIS (ARR / URL Rewrite) ──▶ 외부 지도·주소 API

준비물

  • IIS가 설치된 Windows 서버
  • URL Rewrite 모듈과 Application Request Routing(ARR) 모듈
  • 서버에서 외부 API 주소로의 아웃바운드 443(HTTPS)이 열려 있을 것

설정 순서

1. 프록시 기능 켜기

IIS 관리자에서 서버 노드를 선택하고 Application Request Routing Cache → Server Proxy Settings로 들어가 Enable proxy를 체크한 뒤 적용합니다. 이것을 켜지 않으면 규칙을 만들어도 프록시로 동작하지 않습니다.

2. 사이트에 재작성 규칙 추가

사이트 루트의 web.config에 규칙을 넣습니다. 예시는 /proxy/ 아래 경로를 외부 API로 중계합니다.

<configuration>
  <system.webServer>
    <rewrite>
      <rules>
        <rule name="map-api-proxy" stopProcessing="true">
          <match url="^proxy/(.*)" />
          <action type="Rewrite" url="https://api.example.com/{R:1}" />
          <serverVariables>
            <set name="HTTP_ACCEPT_ENCODING" value="" />
          </serverVariables>
        </rule>
      </rules>
    </rewrite>
  </system.webServer>
</configuration>

api.example.com 자리에는 실제 호출할 API 호스트를 넣습니다. 쿼리 문자열은 기본적으로 그대로 전달됩니다.

3. 서버 변수 허용

위 규칙의 HTTP_ACCEPT_ENCODING을 사용하려면 서버 수준의 URL Rewrite에서 View Server Variables → Add로 해당 변수를 허용 목록에 추가해야 합니다. 허용하지 않으면 500 오류가 납니다.

막히기 쉬운 지점

증상원인과 대처
응답이 깨져 보이거나 JSON 파싱 오류외부 응답이 압축되어 IIS가 다루지 못하는 경우입니다. 위 규칙처럼 Accept-Encoding을 비워 요청합니다.
502 / 502.3, 연결 실패서버에서 외부로 나가는 방화벽·프록시 설정, DNS, 인증서 신뢰를 순서대로 확인합니다. 서버에서 직접 호출해 보면 가장 빠릅니다.
HTTPS 인증서 오류중간·루트 인증서가 서버에 설치되어 있어야 합니다. 사내 장비가 인증서를 바꿔 끼우는 환경이면 해당 루트 인증서를 신뢰 저장소에 추가합니다.
리다이렉트 후 외부 주소로 튕김응답의 Location 헤더에 외부 호스트가 담긴 경우입니다. ARR의 응답 헤더 호스트 재작성 설정을 확인합니다.
큰 응답이 중간에 끊김ARR의 프록시 제한 시간과 요청·응답 크기 제한을 늘립니다.

운영할 때 지킬 것

  • 열린 프록시가 되지 않게 규칙은 호출할 API 경로만 고정해서 만듭니다. 임의의 주소를 받아 중계하면 외부에서 악용됩니다.
  • API 키는 가능하면 서버 쪽에서 붙이도록 하고, 브라우저 코드에 직접 넣지 않습니다.
  • 외부 API가 도메인 등록을 요구하면 프록시 서버의 도메인을 등록해야 합니다.
  • 변경한 규칙은 web.config를 백업해 두고, 적용 후 실제 지도 요청 한두 건으로 바로 확인합니다.
