제각각인 주소 정리하기: 정규화와 지오코딩 오류 줄이기

엑셀에 섞여 있는 도로명·지번·약식 주소를 지오코딩 전에 정리하는 규칙과, 변환 실패를 줄이는 호출 방식·검수 방법을 정리했습니다.

2026.10.13 작성

실패의 대부분은 입력 때문입니다

주소 일괄 변환이 실패하는 이유는 API가 아니라 주소 문자열이 지저분해서인 경우가 훨씬 많습니다. 같은 주소가 사람마다 다르게 적혀 있고, 상세 정보가 한 칸에 뭉쳐 있기 때문입니다. 지오코딩 전에 규칙으로 먼저 정리해 두면 성공률이 눈에 띄게 올라갑니다.

자주 보이는 오류 유형

유형예시대처
괄호 안 부가정보세종대로 110 (시청)괄호와 그 안의 내용 제거
쉼표 뒤 상세주소세종대로 110, 3층쉼표 이후 제거
공백이 여러 개중구  세종대로  110연속 공백을 하나로
시·도 약칭서울 중구 세종대로 110정식 명칭으로 확장
전각 문자·특수 공백전각 숫자 등일반 문자로 정규화
번지·산 번지 혼재산 12-3지번 형식 확인 후 별도 처리

정리 코드 예시

function cleanAddress(raw) {
  return String(raw ?? '')
    .normalize('NFKC')            // 전각 문자·특수 공백 정규화
    .replace(/\([^)]*\)/g, '')    // (건물명) 제거
    .replace(/,.*$/, '')          // 쉼표 뒤 상세주소 제거
    .replace(/\s{2,}/g, ' ')       // 연속 공백 정리
    .trim();
}

const SIDO = {
  '서울': '서울특별시', '부산': '부산광역시', '대구': '대구광역시',
  '인천': '인천광역시', '광주': '광주광역시', '대전': '대전광역시',
  '울산': '울산광역시', '세종': '세종특별자치시', '경기': '경기도',
};
function expandSido(addr) {
  const head = addr.split(' ')[0];
  return SIDO[head] ? addr.replace(head, SIDO[head]) : addr;
}

정규화는 원본을 건드리지 않고 새 열에 결과를 저장하는 것이 원칙입니다. 나중에 왜 이렇게 바뀌었는지 확인할 수 있어야 합니다.

지오코딩 호출할 때

  • 호출 간격을 둡니다. 수천 건을 한꺼번에 던지면 제한에 걸립니다. 건당 수십~100ms 정도의 간격을 두고 순차 처리하는 편이 안정적입니다.
  • 중단과 재개가 가능해야 합니다. 건수가 많은 작업이 중간에 끊기면 처음부터 다시 하게 됩니다.
  • 검색 결과가 여러 건이면 첫 번째를 쓰되, 건수와 주소 종류를 함께 기록해 둡니다.
  • 주소 검색이 실패하면 키워드 검색으로 한 번 더 시도하는 단계를 두면 성공률이 올라갑니다.
  • 호출 한도와 일일 쿼터는 서비스마다 다르니 시작 전에 확인합니다.

결과 검수

변환이 끝났다고 끝이 아닙니다. 다음 세 가지는 꼭 확인합니다.

  1. 미검색 건수를 따로 뽑아서 사람이 눈으로 보고 입력 오류인지 확인합니다.
  2. 변환 전후가 같은 건은 이미 지번이거나 실패한 건입니다. 구분해서 표시해 둡니다.
  3. 무작위로 몇 건을 지도에서 직접 열어 위치가 맞는지 확인합니다.

바로 써 볼 수 있는 도구

이 사이트 자료실에 도로명주소를 지번주소로 바꿔 주는 브라우저 도구를 올려 두었습니다. 엑셀을 올리면 주소를 정리해 변환하고, 결과 엑셀을 내려받을 수 있습니다. 변환 전에 문자열만 정리하고 싶다면 주소 정리 도구를 쓰면 됩니다.
